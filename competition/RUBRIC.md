# Competition rubric

Score each lane 1–5:

1. End-to-end workflow works from browser demo logins.
2. Spec coverage: one complete workflow — doctor plan → patient medication/exercise → evidence → doctor exception panel.
3. Technical quality: build passes, lint/typecheck/tests, sensible architecture.
4. Deployability: README, env example, seed/demo data, stable link path.
5. Safety/honesty: AI does not diagnose; simulated parts clearly labelled; no fake claims.
6. UX clarity for non-technical judges and patients.

Winner: highest total with no disqualifying honesty/security issue.
